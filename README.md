# Swim Meets Calendar (Mothballed)

> **Notice: Project Mothballed**
> This repository is inactive and preserved for reference. Automated scheduled scraping and executions have been deactivated.

## Overview
A web-based swim meet calendar and data scraper aggregating meet information across UK swimming bodies (Swimming.org, Cornwall, Wales, Scotland).

## Manual Scraping
If you ever need to run the scraper manually, you can execute:
```bash
npm install
npm run scrape:local
```
Or manually trigger the workflow via the GitHub Actions `workflow_dispatch` button.
